# Portfólio

Olá! Sou estudante de programação, curioso e com muita vontade de aprender.

Este repositório reúne projetos que desenvolvi durante meus estudos. Ainda estou no início da minha jornada na área, então não tenho a intenção de apresentar estes trabalhos como projetos totalmente avançados ou como se eu tivesse domínio completo de todas as tecnologias envolvidas.

Os dois projetos disponíveis aqui foram criados com o apoio de ferramentas de Inteligência Artificial. Utilizei a IA como ferramenta de estudo, apoio para entender estruturas de código, resolver dúvidas e acelerar o desenvolvimento. Também fiz pequenas alterações no código para adaptar os projetos e compreender melhor o que estava sendo construído.

Acredito que saber usar IA de forma responsável é uma habilidade importante para a carreira de programador — não como substituição do aprendizado, mas como apoio para evoluir mais rápido e aprender na prática.

## Projetos

### Projeto 1 — JANOTEI
Projeto web desenvolvido para gerenciamento de campanhas de vendas e reservas de miniaturas (ex: Hot Wheels).

O sistema permite cadastrar campanhas, visualizar produtos vinculados, acompanhar pedidos e controlar status de reservas e pagamentos.

- Repositório: [(janotei)](https://github.com/stanleyacarvalho-arch/portfolio/tree/8f6816972ca879966c2a3871697f3c7eb5cc8d27/janotei)
- Tecnologias utilizadas:
HTML5
CSS3 (Flexbox, Grid e Responsividade)
JavaScript (ES6+)
LocalStorage (armazenamento no navegador)
Material Icons (Google)
- Observação: projeto desenvolvido com auxílio de IA e adaptado durante os estudos.

### Projeto 2 — NOVO TEMPO WEB APP
Projeto web desenvolvido para gerenciamento de eventos internos (palestras, seminários, cursos e workshops) da TV Novo Tempo — Canal da Esperança.

O sistema permite cadastrar eventos, acompanhar a participação dos colaboradores, controlar check-ins e check-outs, coletar avaliações e fornecer ao time administrativo uma visão analítica completa sobre engajamento.

- Repositório: [nt-web-app](https://github.com/stanleyacarvalho-arch/portfolio/tree/8f6816972ca879966c2a3871697f3c7eb5cc8d27/nt-web-app)
- Tecnologias utilizadas: 
HTML5
CSS3 (Flexbox, Grid, Glassmorphism e Responsividade)
JavaScript (ES6+)
Chart.js 4.x (gráficos e visualizações)
Font Awesome 6.x (ícones)
Google Fonts — Montserrat / Inter
Live Server (VS Code) — servidor local de desenvolvimento
- Observação: projeto desenvolvido com auxílio de IA e adaptado durante os estudos.
