# JANOTEI – Sistema de Gestão de Campanhas e Reservas

Projeto web desenvolvido para gerenciamento de campanhas de vendas e reservas de miniaturas (ex: Hot Wheels).

O sistema permite cadastrar campanhas, visualizar produtos vinculados, acompanhar pedidos e controlar status de reservas e pagamentos.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Grid e Responsividade)
- JavaScript (ES6+)
- LocalStorage (armazenamento no navegador)
- Material Icons (Google)

## 📌 Funcionalidades

- Dashboard com navegação lateral e menu inferior
- Cadastro e gerenciamento de campanhas
- Controle de status de campanhas
- Listagem de pedidos por campanha
- Alteração de status de pedidos
- Persistência de dados usando LocalStorage
- Layout responsivo (desktop e mobile)

## 💾 Armazenamento

O projeto utiliza **LocalStorage** para salvar dados no navegador.  
Não possui backend ou banco de dados externo.

## 🚀 Como Executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `dashboard.html` no navegador.
3. O sistema roda localmente sem necessidade de servidor.

## 📂 Estrutura

- `dashboard.html` – Página inicial
- `disparos-whatsapp.html` – Gestão de campanhas
- `nova-campanha.html` – Criação de campanha
- `app.js` – Lógica principal da aplicação
- Demais arquivos HTML complementares

## 📎 Observações

Este projeto é focado em frontend e organização de interface.  
Foi desenvolvido sem uso de frameworks (React, Vue, Angular), utilizando apenas JavaScript puro.
