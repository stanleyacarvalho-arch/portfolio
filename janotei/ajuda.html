help Perguntas Frequentes
Como funciona a integração com WhatsApp?
expand_more
O sistema monitora mensagens do seu grupo do WhatsApp em busca de palavras-chave como "quero", "reserva" ou "interesse". Quando detecta essas palavras, automaticamente registra a reserva do cliente no sistema.
Posso usar o sistema para outros produtos além de Hot Wheels?
expand_more
Sim! O sistema foi desenvolvido para ser flexível e pode ser usado para qualquer tipo de produto. Você pode criar categorias personalizadas e adaptar as configurações para seu negócio.
Como faço backup dos meus dados?
expand_more
Acesse "Mais > Backup dos Dados" no menu. Selecione quais dados deseja exportar (produtos, clientes, pedidos, etc.) e clique em "Gerar Backup". O arquivo será baixado automaticamente.
Posso ter múltiplos usuários no sistema?
expand_more
Sim, você pode adicionar outros usuários através de "Mais > Gestão de Usuários". É possível definir diferentes níveis de permissão para cada usuário.
O que acontece se eu excluir um produto por engano?
expand_more
Todas as ações ficam registradas no "Histórico de Atividades". Embora não seja possível desfazer automaticamente, você pode recriar o produto usando as informações do histórico ou restaurar um backup anterior.
